What this prototype does

Arm microphone once, then hold the talk button. Overlapping snapshots update the transcript while held. Release submits the final text. Escape or a cancelled pointer discards the recording. The microphone stays armed between presses, but audio uploads occur only during a hold or its final transcription.

One temporary draft uses the native agent’s normal instructions, conversation context, selected model, and tool definitions. It executes no tools and writes no conversation messages before release. The server reuses it only if final text and context still match. Drafts expire after 30 seconds and never create saved forked sessions.

Pressing talk cancels queued playback. Echo cancellation is requested. Each recording is capped at 30 seconds; at that limit it is discarded rather than sent without your release. Stop shuts down microphone tracks and cancels pending requests. Full hands-free voice is deferred. Installed Iugum Chat is separate from this experimental page.
